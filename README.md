**你的日常，变成它的世界；它认识你，陪着你，长成它自己。**

日常里的东西被掌机拍下来、听到，就变成像素，飞进团子的世界：梧桐叶变成米糕家的屋顶，闹钟变成魔法学院的大钟，锅盖变成秋日村的盾。楼下修车大哥的口哨声音大得整条街都听得见，阿柚最爱听，它就成了霓虹港路灯唱的歌。团子从这些日常里认识主人，记忆册只给主人看；和朋友的掌机碰一碰，团子们也认识了彼此。

结尾是一个不剪断的长镜头：冒险结束，霓虹港缩回书桌上的掌机屏幕里。已经是深夜了，阿柚还在写作业。没人叫它，青团自己醒了，在它的家里点亮一盏灯，坐到窗边陪着她。
