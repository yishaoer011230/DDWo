全片不配音。团子用图画气泡和自己的叫声“说话”，人用绘本字幕；每个卖点用一张彩色卡片标出来：🟦 看见 · 🟨 记住 · 🟩 只属于你 · 🟧 现实改变世界 · 🟪 社交。
